# Alfassa

A premium Progressive Web App featuring clean architecture, Firebase integration, and future AI capabilities.

## Architecture

Alfassa is built with a feature-based structure separated from core engines:

*   **Frontend:** React, TypeScript, Vite, Tailwind CSS, PWA setup.
*   **Backend:** Firebase Authentication, Firestore, Storage.
*   **State:** Context / React Hooks (Future: Zustand).

See `Architecture.md` for the database schema and conceptual relationships.
See `FolderStructure.md` for the directory layout.

## Setup

1. Configure environment variables in `.env`.
2. Install dependencies: `npm install`
3. Run development server: `npm run dev`
